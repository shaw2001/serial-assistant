# 串口助手 v0.1.8 · 安全修复

请下载本页 `SerialAssistant-0.1.8-win-x64.exe` 替换旧程序。v0.1.0–v0.1.7 已停止支持，将撤下旧 Release、标签和匹配的构建下载；Git 提交历史保留用于追溯。已下载的旧程序需要用户自行删除。

- 严格校验并规范化配置，拒绝未知分组、重复字段及非法模式；修复指令提示中的 HTML 注入。
- WebView 禁止外部导航和弹窗，拒绝页面权限，校验原生消息来源，并为每次启动生成独立调用凭证。Windows 发布测试会实际验证导航拦截和未授权调用拒绝。
- 停用扫描整个本地目录的旧发布脚本，避免上传未跟踪凭据。
- 默认关闭原始记录、草稿/历史持久化和自动更新检查。可在“配置方案”明确开启明文保存或自动更新；手动检查更新仍可用。
- 配置导出排除发送草稿和历史。快捷指令可能含密码，分享前仍需检查。旧日志不自动删除，可从日志目录归档或清理。
- 原始日志总量限制为 1 GiB，超过时停止写入并报告错误；保留已有文件，不自动删除用户记录。
- 补全超时或取消后暂停发送，必须清空设备输入行并明确确认。重新连接串口不等于清空设备 Shell。
- 更新链接仅允许本仓库的 HTTPS Release 页面；拒绝重定向、草稿及预发布元数据。
- Go 升级至 1.26.9，x/sys 升级至 0.44.0，esbuild 升级至 0.28.2；加入漏洞和敏感信息发布门禁。
- 只读构建与发布分离，Actions 固定提交，构建不持有仓库写凭据。

更新检查只请求 GitHub 版本信息，不发送串口日志或配置；GitHub 可以看到出口 IP 和应用版本。Windows EXE 未配置 Authenticode 证书；请从本仓库下载并核对 SHA256SUMS.txt。软件不会自动下载或执行更新。
