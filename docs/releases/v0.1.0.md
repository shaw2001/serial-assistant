# 串口助手 v0.1.0

首个可连接真实串口的本地 MVP，支持 Windows 10 / 11 x64。

- 最多四个独立串口会话，自动枚举、手动端口和自定义波特率。
- 文本 / HEX / 混合显示，UTF-8 / ASCII / GBK、结尾符及最终字节预览。
- 单次 / 周期发送、紧凑快捷指令和设备独立的发送历史。
- 暂停、搜索高亮、过滤、原始会话记录、TXT / JSON / JSONL 导出。
- 配置方案与本机自动保存，固定浅色和原始 OPPO Sans。

下载 `Setup` EXE 安装，或完整解压 ZIP 后运行 `SerialAssistant.exe`。`SHA256SUMS.txt` 可核对下载文件。无需安装 Node.js，USB 适配器需要自己的驱动。

已执行自动化后端 / UI 测试和双 PTY 原生串口集成验证，GitHub 发布流程会在 Windows 构建，并检查桌面启动。物理 Windows USB 设备、8 小时压力、睡眠恢复和全部 DPI 组合仍需实体验收。本版本未使用代码签名证书。

TX 仅表示已提交驱动；原始记录以主机时间与接收批次保存，不是协议帧。显示缓存有上限，完整记录从落盘会话导出。
