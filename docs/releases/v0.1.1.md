# 串口助手 v0.1.1

轻量单文件 Windows 10 / 11 x64 版本。下载 `SerialAssistant-0.1.1-win-x64.exe`，直接双击运行，无需安装或解压。

- 接收区默认 14px 等宽字体，保留空格和表格列对齐；界面继续使用内嵌 OPPO Sans。
- 可设置自动 / 仅 CRLF / 仅 LF / 仅 CR / 不分行 / 按接收批次；接收规则与发送结尾符独立，原始字节保留。
- 可调整字号、自动折行、显示时间和方向。默认连续文本、水平滚动，适合 RT-Thread 线程表。
- 接收区随窗口伸展，发送区和底栏压缩，提示以短暂浮层显示。
- 已连接时可修改预设或自定义波特率，点击“应用并重连”。重连停止周期发送，保留日志、统计和其他设备连接；失败后显示未连接，可修正参数再连接。
- Windows 后端改为 Go / Win32 串口，界面使用系统 WebView2；UI、脚本和字体全部嵌入 EXE，没有捆绑 Electron 或启动解压过程。
- 保留四设备、文本 / HEX / 混合、UTF-8 / ASCII / GBK、周期发送、快捷指令、发送历史、原始记录与导出功能。

运行需要 Microsoft WebView2 Runtime，Windows 11 与多数 Windows 10 已有；少数旧版或精简系统缺少时，程序会提示前往微软官方下载 Evergreen Runtime： https://developer.microsoft.com/microsoft-edge/webview2 。应用运行与串口收发不联网。

配置和日志使用 `%APPDATA%\SerialAssistant`，WebView2 缓存也保存在用户配置目录。软件未使用代码签名证书。物理 USB 串口、睡眠恢复、长时间满速和不同机器 DPI 仍需实体验证。v0.1.0 保留供回退。
