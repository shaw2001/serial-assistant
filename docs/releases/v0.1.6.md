# 串口助手 v0.1.6

- 日志可视行数提升约 40%：同屏浏览更多串口日志。
- 连接控件并入会话标签行：设备、波特率、串口参数与连接按钮同行，节省整块连接栏高度。
- 三层日志工具栏合并为一行：搜索改为聚焦展开（Ctrl+F），接收换行 / 字号 / 折行 / 时间方向收进 ⚙ 弹层。
- 发送面板合并行：最终字节预览并入底行，与历史、周期发送、发送按钮同一行。
- 修复 Tab 补全偶发卡死：设备持续刷屏导致补全回应迟迟无法解析时，3 秒超时自动恢复本地输入；也可按 Esc 手动取消补全。
- 全部功能与快捷键保持不变；窄屏与触摸适配同步更新。

Windows 发布流程会验证成品启动、版本、字体和布局。
