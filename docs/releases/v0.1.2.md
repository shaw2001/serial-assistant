# 串口助手 v0.1.2

下载 `SerialAssistant-0.1.2-win-x64.exe`，双击运行，无需安装或解压。保留浅色界面、OPPO Sans、四串口独立会话与轻量单文件架构。

- 发送框改为 **Enter 发送、Shift+Enter 换行**，兼容原来的 Ctrl+Enter。
- 中文输入法确认候选字不会触发发送；按住按键和正在发送时不会重复提交。
- 文本模式下，**Tab 将单行输入前缀和 0x09 发送到当前串口**，不追加 CR、LF 或 CRLF，也不会切换到其他界面控件。空输入 Tab 可请求 RT-Thread/FinSH 命令列表。
- 前缀交给设备后，发送框清空，补全结果显示在接收区；可继续输入参数，按 Enter 或“执行”结束设备中的指令。连续 Tab 只发送新输入和 Tab，后续回车只发送追加内容与所选结尾符，避免前缀重复。
- Enter 使用当前选定的发送结尾符；RTT 执行指令请选择 CR、LF 或 CRLF。“无结尾符”继续按原样发送字节。
- 补全状态按串口隔离；当前设备有待执行输入时暂时禁用快捷指令、历史填入与周期发送，完成后恢复。
- Shift+Tab 可离开发送框。HEX 模式、其他控件及对话框保持正常 Tab 焦点导航。
- 多行输入用 Enter 发送，Tab 不会把其中的换行提交给设备。

补全由设备固件中的 Shell 提供，软件负责转发输入和 Tab；结果显示在接收区。保留原始日志字节。关闭或重连会清除本地补全状态，但不会替设备执行或取消指令。

运行环境与 v0.1.1 一致：Windows 10 / 11 x64 和 Microsoft WebView2 Runtime。配置与日志使用 `%APPDATA%\SerialAssistant`。v0.1.0、v0.1.1 保留。

发布前验证：19 项 JavaScript 测试、Go 并发与串口服务测试，以及两个真实 Linux 内核 PTY 的 Tab/Enter 字节、独立收发、重连和拔出测试。Windows 流水线会实际启动成品，检查版本、体积、字体和布局，成功后才公开 Release。物理 RTT 开发板尚未在本环境测试。
